# Finance and SQL practice

Use the public yfinance package or another documented market data API to collect a small set of ticker history; record the retrieval date, missing values, and API/provider terms. Reproduce descriptive returns and plots only. Historical prices do not forecast returns.

`queries.sql` contains parameterized examples for relational joins and grouped summaries. Adapt them to a public census, school, or flight dataset after recording the schema and license. Do not commit credentials, licensed course datasets, or personal financial records.
