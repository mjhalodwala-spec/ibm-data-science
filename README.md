# IBM Data Science: Retrospective Project Portfolio

A newly reconstructed portfolio mapped to public IBM Data Science Professional Certificate project descriptions. These artifacts were written after the certificate was earned; they are not recovered Coursera submissions, graded work, or a record of what was completed during the course. Course-only assessments and private lab instructions are not reproduced.

## Projects

| Project | Course skills represented | Entry point |
|---|---|---|
| SpaceX Falcon 9 landing analysis | Data collection, wrangling, EDA, visualization, classification and stakeholder reporting | [`projects/spacex/`](projects/spacex/) |
| Loan repayment modeling | Classification, leakage-aware evaluation, threshold selection | [`projects/loan-risk/`](projects/loan-risk/) |
| Housing price modeling | Regression, preprocessing, cross-validation and error analysis | [`projects/housing/`](projects/housing/) |
| Flight reliability dashboard | Data shaping and decision-oriented visualization | [`projects/flights/`](projects/flights/) |
| Financial data and SQL practice | API data collection, Pandas and relational queries | [`projects/finance-sql/`](projects/finance-sql/) |

See [`CURRICULUM_MAP.md`](CURRICULUM_MAP.md) for the mapping to the certificate. The portfolio uses public data or clearly labeled synthetic examples. Results must be produced locally; no performance claims are asserted here.

## Run

Python 3.10+ is recommended. Install with `python -m pip install -e .`. Each project README lists its data source and command. Data files are not committed when the provider's license or stability is unclear.
